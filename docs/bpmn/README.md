# BPMN: сервис подбора КТРУ

[ktru-mvp.bpmn](ktru-mvp.bpmn) — схема раннего MVP с дорожками поставщика и сервиса.
Она показывает выбор семейства, извлечение, проверку, уточнения и заполнение карточки.
Она не отражает точный порядок текущего S0.

В схеме поиск и подтверждение семейства стоят до извлечения. В текущем коде
`service/pipeline.py` правила извлекают факты **до поиска**, даже без найденного семейства.
UI получает `/parse`, затем запускает `/analyze` для принятой ревизии, если модель не отключена.
Модель также извлекает независимо от выбранного семейства. Результат проходит проверку цитат,
объекта, чисел и единиц, объединение, привязку и сужение.

Один оставшийся кандидат не достаточен для окончательного кода: нужны подтверждённое семейство
и полная загрузка его ACTIVE конечных позиций. Готовность карточки проверяется отдельно.
Схема не показывает полностью черновики UI, проверки поздних ответов и области источников `s0-4`.

Действующий порядок и ограничения описаны в [ARCHITECTURE.md](../../ARCHITECTURE.md).
Для демонстрации полной архитектуры BPMN нужно обновить. Сверено с кодом 10.10.2026.
